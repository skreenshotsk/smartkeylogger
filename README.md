# Smart Keylogger (Macro Recorder)

Десктопное приложение для записи и воспроизведения макросов клавиатуры и мыши с графическим интерфейсом, планировщиком запуска и синхронизацией между компьютерами в локальной сети.

## Запуск

```bash
cd smart-keylogger
dotnet run
```

Сборка релиза:

```bash
dotnet publish -c Release
```

Требования: Windows, [.NET SDK 10](https://dotnet.microsoft.com/download) (или совместимая версия с поддержкой `net10.0-windows`).

## Используемые технологии

Приложение реализовано на **C#** и платформе **.NET 10** (`net10.0-windows`) в виде нативного Windows-приложения (`WinExe`). Пользовательский интерфейс построен на **Windows Forms** — формы, панели, кнопки, списки и диалоги (в том числе выбор файла, сохранение макроса и задание времени выполнения).

Захват ввода при записи выполняется библиотекой **SharpHook** (обёртка над **libuiohook**): глобальные хуки клавиатуры и мыши позволяют фиксировать нажатия, отпускания и перемещения курсора независимо от активного окна. Воспроизведение и часть системных действий реализованы через **P/Invoke** к **WinAPI** (`user32.dll`): эмуляция клавиш (`keybd_event`), событий мыши (`mouse_event`, `SetCursorPos`), регистрация глобальных горячих клавиш (`RegisterHotKey` / `UnregisterHotKey`), определение и переключение раскладки клавиатуры (`GetKeyboardLayout`, `ActivateKeyboardLayout`), а также вспомогательные вызовы (`GetForegroundWindow`, `GetAsyncKeyState`, `GetSystemMetrics`).

Данные макросов, настроек горячих клавиш и параметров редактора хранятся локально в файлах **JSON**. Сериализация и десериализация выполняются встроенным модулем **System.Text.Json**; макросы сохраняются в каталоге `Macros`, конфигурация горячих клавиш — в `hotkeys.json`, дополнительные настройки — в `settings.json`.

Удалённая синхронизация между экземплярами приложения в сети построена на **System.Net.Sockets**. Обнаружение устройств в локальной сети выполняется по **UDP**: широковещательные и мультикаст-объявления (группа `239.255.77.77`), обмен служебными сообщениями в формате JSON. Передача команд воспроизведения (старт, пауза, остановка) и payload макроса — по **TCP** на выделенном порту. Для обхода сетевых интерфейсов используется **System.Net.NetworkInformation**.

Фоновая логика записи, воспроизведения и сетевых циклов построена на **async/await** и **System.Threading.Tasks** (`Task`, `CancellationToken`, `CancellationTokenSource`), что позволяет не блокировать UI при длительном воспроизведении и корректно отменять операции. Обновление таймеров записи, воспроизведения и планировщика — через **System.Windows.Forms.Timer**.

Управление проектом и зависимостями — **MSBuild** / **.NET SDK**; внешняя NuGet-зависимость: **SharpHook 5.3.0**. Контейнеры, СУБД и брокеры сообщений в проекте не используются — приложение рассчитано на автономную работу на Windows с опциональным обменом по локальной сети.
